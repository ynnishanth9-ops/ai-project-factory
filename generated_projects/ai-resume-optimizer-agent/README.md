# AI Resume Optimizer Agent

A LangChain-based AI agent that analyzes resumes against job descriptions and generates targeted improvement suggestions.

## Features

- Resume text analysis
- Job description keyword extraction
- Skill gap detection
- Improvement report generation

## Tech Stack

Python · LangChain · OpenAI API

## Project Purpose

This project is part of an AI automation portfolio focused on building practical tools using Python, LangChain, LangGraph, APIs, and workflow automation.

## How It Works

Input data
    ↓
AI processing workflow
    ↓
Generated analysis / response
    ↓
Output report

## Setup

pip install -r requirements.txt
python app.py
